# AIStack

AI 工具与模型选型指南 —— 把能力、速度、价格、趋势摆到一张表上对比。

## 特性

- 按任务组织（写作 / 图像 / 音频 / 编程 / 多模态）
- 四维评分：能力、速度、价格、趋势
- 各厂商计费单位统一折算

## 开始

```bash
git clone https://github.com/leisvip/AIStack.git
cd AIStack
```
